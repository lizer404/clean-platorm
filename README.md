# CleanPlatform

Калькулятор клининга на Next.js и Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Возможности

- Выбор типа уборки: поддерживающая, генеральная, после ремонта
- Параметры квартиры и санузлов
- Дополнительные услуги с иконками
- Живой пересчёт итоговой стоимости
- Адаптивная вёрстка для desktop и mobile
